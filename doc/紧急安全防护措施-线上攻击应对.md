## ⚡ 立即执行的防护措施

### 1. 紧急IP封禁
```bash
# iptables封禁攻击IP
iptables -I INPUT -s 223.73.36.215 -j DROP

# nginx层面封禁
docker exec 9color_nginx_prod sh -c "
echo '# 紧急封禁攻击IP - $(date)
deny 223.73.36.215;
deny 223.73.0.0/16;' >> /etc/nginx/conf.d/emergency-block.conf"

# 重载nginx配置
docker exec 9color_nginx_prod nginx -s reload
```

### 2. 加强SSH安全配置
```bash
# 修改SSH端口（当前9922）
# 禁用root密码登录，改用密钥认证
# 设置SSH登录失败锁定

# 在/etc/ssh/sshd_config中添加：
PermitRootLogin no
PasswordAuthentication no
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 2
```

### 3. 安装fail2ban防护
```bash
# 如果未安装
apt update && apt install fail2ban

# 配置SSH防护规则
cat > /etc/fail2ban/jail.local << EOF
[sshd]
enabled = true
port = 9922
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
bantime = 86400
findtime = 600
EOF

systemctl restart fail2ban
```
