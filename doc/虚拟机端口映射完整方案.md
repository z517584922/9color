## 🛠️ MikroTik配置步骤

### 配置原理
每个VM需要2个规则：
1. **DSTNAT规则** - 端口转发
2. **防火墙规则** - 允许访问

### 基础服务VM配置示例 (Ubuntu 20)

#### 1. Web服务端口映射 (8080)
**IP → Firewall → NAT → 添加新规则**

```
General标签：
- Chain: dstnat
- Protocol: tcp
- Dst. Port: 8080
- In. Interface: ether1

Action标签：
- Action: dst-nat
- To Addresses: 192.168.99.10
- To Ports: 80
```

**防火墙规则：**
```
General标签：
- Chain: forward
- Protocol: tcp
- Dst. Address: 192.168.99.10

- Action: accept
```

### 基础服务VM配置 (Ubuntu 20.04)

**编辑netplan配置文件：**
```bash
sudo nano /etc/netplan/01-netcfg.yaml

network:
  version: 2
  ethernets:
    ens33:  # 或 eth0，根据实际网卡名称
      dhcp4: no
      addresses: [192.168.99.10/24]
      gateway4: 192.168.99.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]

# 应用配置
sudo netplan apply

# 重启网络服务
sudo systemctl restart systemd-networkd
```


## 🔍 端口冲突避免

### 端口分配原则

1. **系统端口 (1-1023)：** 避免使用
2. **常用服务端口：** 
   - 22 (SSH) → 改为 2222
   - 80 (HTTP) → 改为 8080, 8081...
   - 443 (HTTPS) → 改为 8443, 8444...
   - 3306 (MySQL) → 可直接使用
   - 5432 (PostgreSQL) → 可直接使用

3. **推荐端口范围：** 8000-9999

### 端口规划表

| 服务类型 | 建议端口范围 | 示例 |
|----------|-------------|------|
| Web服务 | 8080-8089 | 8080, 8081, 8082 |
| API服务 | 3000-3099 | 3000, 3001, 3002 |
| 数据库 | 原端口 | 3306, 5432, 27017 |
| SSH | 2200-2299 | 2222, 2223, 2224 |
| 开发服务器 | 8000-8099 | 8000, 8001, 8002 |

## 🛡️ 安全配置建议

### 1. 防火墙规则顺序
确保accept规则在drop规则之前：
```
0  accept  - 允许VM1访问
1  accept  - 允许VM2访问
...
N  drop    - 拒绝其他连接
```

### 2. 限制源IP (可选)
如果只需要特定IP访问：
```
General标签添加：
- Src. Address: 您的固定IP/32
```

### 3. 连接限制 (可选)
防止DDoS攻击：
```
Advanced标签：
- Connection Limit: 10,32
```
